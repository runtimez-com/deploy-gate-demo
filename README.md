# deploy-gate-demo

Test fixture for the runtimez deployment-risk gate. Plain manifests in `k8s/`, deployed to `rtz-gate-demo` on the
rtz-eks test cluster by Argo CD (Application `argocd/deploy-gate-demo`).

- `pr-gate.yml` scores every PR against `main` (pre-apply) and blocks at HIGH.
- `post-deploy-gate.yml` waits on every merge for Argo CD to roll the commit out and judges the deploy.

Generated by `eac/scripts/scenario/deploy-gate-demo.sh`.
